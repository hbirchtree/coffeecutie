# Cache support

The RuneScape cache parser supports caches between v194 (maybe cache v184 too) up to v374.
There is also basic support for the last Runescape Classic cache.
The following caches have been tested:

| Cache version         | Map loads? | Models load? | Notes                                                      |
|-----------------------|------------|--------------|------------------------------------------------------------|
| RSC v235 (2004-01-07) | ✅         | ❌           | Final official Runescape Classic cache                     |
| v194 (2004-01-07)     | ✅         | ✅           | RS2 beta era                                               |
| v225 (2004-03-29)     | ✅         | ✅           | RS2 launch                                                 |
| v245 (2004-07-05)     | ✅         | ✅           | Morytania added                                            |
| v289 (2005-01-18)     | ✅         | ✅           | Mor'ton, Tirannwn, Rellekka added                          |
| v336 (2005-09-19)     | ✅         | ✅           | Ape Atoll, Lletya, Port Phasmatys, more desert areas added |
| v356 (200X-01-30)     | ✅         | ✅           | More desert areas, Barrows, Mage Training Arena added      |
| v374 (2006-04-20)     | ✅         | ✅           | Falador redesign, Burgh de Rott                            |
| v455 (2007-04-03)     | ❌         | ❌           | Lots of changes                                            |
